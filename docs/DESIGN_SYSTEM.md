# Design System

## Design Direction

The website should look like a premium modern technology/startup platform.

Reference qualities:

- Developer-focused
- Technical
- Clean
- Professional
- Modern
- Trustworthy
- Educational
- Minimal

It must not look like a generic college website.

---

## Visual Principles

Prioritize:

- Strong typography
- Generous whitespace
- Clear hierarchy
- Consistent spacing
- Restrained visual effects
- Professional cards
- High readability
- Responsive layouts

---

## Color

Use a professional technology-oriented color system.

Avoid excessive colors.

Use:

- Primary brand color
- Neutral background
- Surface colors
- Text hierarchy
- Accent color
- Semantic success/warning/error colors

The final palette should feel modern and trustworthy.

---

## Typography

Typography should prioritize:

- Readability
- Clear hierarchy
- Strong project titles
- Comfortable long-form reading
- Technical content readability

Use a consistent type scale.

---

## Cards

Cards should be:

- Clean
- Consistent
- Information-dense without being cluttered
- Visually scannable

Project cards should clearly communicate:

Project title
Technology
Difficulty
Project type
Short description
Key skills

---

## Animations

Use subtle animations.

Appropriate:

- Hover states
- Small transitions
- Fade/slide entrance
- Button interactions
- Navigation transitions

Avoid:

- Excessive motion
- Distracting parallax
- Long animations
- Animation on every element

Respect reduced-motion preferences.

---

## Responsive Design

Design mobile-first.

The website must work well on:

- Mobile
- Tablet
- Laptop
- Large desktop

Do not simply shrink the desktop design.

Mobile navigation, cards, filters, tables and long-form content should be intentionally designed.

---

## Project Pages

Project pages should prioritize reading and technical comprehension.

Use:

- Clear section headings
- Sticky or accessible table of contents where useful
- Code blocks where appropriate
- Architecture diagrams
- Technology badges
- Information cards
- Callout boxes
- Related content

Avoid visual clutter.

---

## Blog Pages

Blog pages should feel like professional technical publications.

Prioritize:

- Reading width
- Typography
- Table of contents
- Headings
- Code blocks
- Images/diagrams
- Related articles
- Project CTAs

---

## Trust

The UI should communicate:

"This is a serious technical resource."

It should not communicate:

"This is a student template generated from a generic website builder."
