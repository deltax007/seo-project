# Development Roadmap

## Phase 0 — Planning

Before writing significant production code:

- Inspect repository
- Select appropriate technology stack
- Define folder structure
- Define content model
- Define URL architecture
- Define SEO architecture
- Define design system
- Define reusable components
- Document important decisions

Do not begin by generating hundreds of pages.

---

# Phase 1 — Foundation

Build:

- Application shell
- Global layout
- Navigation
- Footer
- Typography
- Design tokens
- Responsive system
- Core reusable components

Deliverable:

A polished empty platform shell.

Build:

# Phase 5 — Search

Implement:

- Search results

- Language filtering
- Difficulty filtering

- Domain filtering

Ensure the architecture can scale beyond the initial dataset.

# Phase 8 — Content Scaling

Once architecture is validated:

- Test search
- Test filters
